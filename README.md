# 🚀 Kali Super Tool (Rust Edition) 🦀

12 yaşında, düşük sistemli bilgisayarlar için tamamen **0 MB bağımlılık (No-Crate)** ve minimum bellek tüketimiyle geliştirdiğim ultra hafif sistem optimizasyonu ve güvenlik aracı! 

Bu projeyi emektar bilgisayarım **Kali** (i5-4200U, 4GB RAM, 119GB SSD) üzerinde, sistemi hiç yormadan ışık hızında çalışacak şekilde Rust ile kodladım.

## ⭐ Neden Yıldız (Star) Vermelisiniz?
*   **Ultra Hafif (Lightweight):** Dışarıdan hiçbir ağır kütüphane kullanılmamıştır, sadece Rust standart kütüphanesi (`std`) ile yazılmıştır.
*   **4 GB RAM Dostu:** Bellek sızıntısı yapmaz, çökmez ve bilgisayarı kilitlemez.
*   **Çok İşlevli:** Günlük hayatı kolaylaştıran 3 kritik aracı tek çatı altında toplar.

## 📦 Özellikler

### 🧠 1. Smart RAM Purger (RAM & Ön Bellek Temizleyici)
Windows'un arka planda RAM'i şişiren gereksiz servislerini (SearchIndexer, OneDrive vb.) ve DNS önbelleğini Rust hızıyla temizler.

### 📂 2. Lightning File Organizer (Masaüstü Düzenleyici)
Masaüstündeki dağınık dosyaları uzantılarına göre (Kodlar, Resimler, Belgeler) SSD hızını sonuna kadar kullanarak saliseler içinde klasörler.

### 📝 3. Nano Crypto Notes (Güvenli Notlar)
Günlük hayatta aldığınız notları düz metin olarak değil, bit düzeyinde **XOR Cryptography** kullanarak askeri düzey mantıkla şifreler ve diske güvenli şekilde kaydeder.
